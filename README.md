# 🛒 Simple E-Commerce (Java Servlets + JSP + MySQL)

A simple **e-commerce web app** built with **Java Servlets, JSP, JDBC, and MySQL**.  
It allows users to browse products, add to cart, place orders, and manage them.  
This project is for **learning/demo purposes**.

---

## 🚀 Features
- User registration & login  
- Product listing & details  
- Cart & checkout  
- Order management  

---

## 🛠️ Requirements
- Java 11+  
- Apache Tomcat 10+  
- MySQL  
- JDBC driver (`mysql-connector-java.jar`)
